# IanVim
This repository contains my personal (opinionated) NeoVim config.

# How to install
Not that anyone besides me *should* install this (at least not without your own modificaitons), but if you *really* want to... just run the below command:
```sh
mkdir -p ~/.config && cd ~/.config && git clone git@github.com:iwotastic/ianvim.git nvim
```
